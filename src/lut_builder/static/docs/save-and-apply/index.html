Save, export, and apply

Generate a cube

Section titled “Generate a cube”

Keep a pair of files

Save the cube for the device applying the transformation and setup JSON for future edits. A cube cannot be imported as an editable setup.

The Export LUT sheet shows the profile, target, cube size, and resolved output filename. Choose Download LUT to download a .cube. While the browser worker is generating, progress appears and Cancel can stop the job. Correct any validation error before trying again.

The download uses applied band colors. A palette draft must be accepted with Use palette first. A separate Download checked .cube action in camera verification retains the exact bytes used for that check; use it when you need that identity.

The browser controls the download folder and may append a suffix for a repeated filename. The filename’s settings-derived ID is not a cryptographic proof of a checked artifact. Verification provenance supplies the cube’s SHA-256 for that purpose.

Choose an export destination

Section titled “Choose an export destination”

In Export, choose where you will use the LUT. External monitor and editing software options explain which signal to feed into the transform; check the specific host’s cube-size and range requirements. Loading guidance opens after a successful download and can also be expanded before generating.

For Lumix S5IIX · V-Log View Assist, export requires Panasonic V-Log input, 17³ or 33³, and full-range output. Use V-Log, 33³ and full range applies these settings explicitly. This destination uses an eight-character settings ID for the download filename to fit SD/SDHC card limits. An imported look must be removed or replaced before changing its declared input.

Copy the .cube into the SD card’s root directory. Use an alphanumeric filename; SD/SDHC cards allow at most 8 characters before the extension. In LUT Library, choose a slot, Load, the card and the file. A used slot is overwritten. Record in V-Log, choose the LUT under V-Log View Assist → LUT Select, and enable LUT View Assist (Monitor). REAL TIME LUT applies false colors to the recorded image; use View Assist for monitoring. HDMI assist also applies the LUT to that output.

See Panasonic’s LUT file requirements and V-Log View Assist instructions. The builder’s checks are not a substitute for testing the actual camera path.

Export and import JSON

Section titled “Export and import JSON”

Export setup file saves the editable LUT setup: profile, target, bands and their applied colors, IRE interpretation, warnings, range, cube size, and filename settings. Keep this beside your cube so you can revise it later.

Import JSON loads a saved setup into the editor. Check the profile, range, IRE interpretation, bands, and output name after loading. An invalid file produces an error; correct the file or choose a known-good export. Importing a cube as JSON is not supported.

JSON does not back up your entire saved-palette library, uploaded media, or an unaccepted palette draft. Applied band colors are preserved.

Compose an imported look

Section titled “Compose an imported look”

In Configuration, choose Import .cube LUT. Confirm the actual camera input, output primaries, output transfer and full/legal output range, then choose Confirm and apply look. For example: Panasonic V-Log / V-Gamut → Rec.709, gamma 2.2, full. This also selects source-camera IRE and turns monochrome off so the look is preserved outside diagnostic bands. A filename cannot identify colorimetry.

Supported files are a single baked 3D Iridas cube, size 2–65, up to 16 MiB, with finite RGB rows and an optional increasing domain. 1D and combined shaper LUTs are not supported: bake those into a single 3D cube first. Unsupported/malformed files leave the current look intact and show a recovery message.

Look / Look + diagnostics changes viewing only. The camera exposure reference shows original neutral camera-code patches; the diagnostic view uses the sampled exported transform. Camera-media verification compares the imported look and the combined cube on preserved source samples. Downloads and numerical inspection always include diagnostics. Very narrow markers can blur or miss cube nodes, even at 65³; use positive widths and check the sampled result.

The exported combined LUT replaces the original viewing LUT at its original camera-log input. Do not apply the creative LUT first and then feed its graded output into the combined LUT. Exposure bands measure recorded source-log exposure before the look, never exposure reconstructed by inverting a grade or physical sensor saturation.

Portable setup version 3 embeds the original cube and its content identity, together with your confirmed interpretation. It can move between phone and desktop without reattaching the file. A damaged/missing imported asset fails visibly rather than substituting a different look. No-look setups remain compatible with version 1. Large LUTs can exceed browser storage quota: heed save errors and export setup JSON before closing if restoration could not be saved.

Session status and recovery

Section titled “Session status and recovery”

The workspace saves your setup on this device. Open Settings → Saved setups to see its save status and Restore previous setup after a setup replacement. This recovery lasts for the current page session and is separate from band-edit undo. Camera media must be selected again after reopening.

Save failures remain visible on your current screen. Follow the retry or backup actions before closing; routine save confirmations do not appear below editing controls.

Palettes and setups are different

Section titled “Palettes and setups are different”
Saved itemIncludesWhere it lives
Named paletteColor draft, anchor positions, blend and adjustment settingsThis browser’s palette library
Named LUT setupComplete LUT settingsBrowser app’s Saved LUT setups library
Exported JSONComplete applied LUT settingsA file you save and can transfer
Exported cubeSampled transformation for a compatible hostA file; not an editable setup

Under Save and reuse palettes, choose a saved palette to load its draft. Palette name names it; Save new palette creates a library entry, Replace saved palette overwrites the selected entry with the draft, Rename saved palette changes its name, and Delete saved palette removes it. Saving a draft does not apply it to bands. Names must be valid and distinct; the library is limited to 100 palettes.

In the browser app, enter a Preset name and choose Save current setup. Select a Saved setup, then Load setup to use it, or Delete setup to remove it. Pay attention to any replacement or load confirmation shown. Named setups and named palettes are independent.

Browser storage is tied to the browser, profile, and site address. The hosted app and http://127.0.0.1:8765/ have different libraries. Private browsing, blocked storage, clearing site data, or browser cleanup can remove or prevent saves. Export JSON before closing or clearing storage; saving is not cloud synchronization.

Saved locally is not backed up. Export JSON before clearing browser data or moving to another device. It preserves applied settings, not the entire palette library.

Apply the cube

Section titled “Apply the cube”
StageMust agree with
Signal entering the LUTSelected camera log and gamut
LUT outputSelected display target and Full / Legal handling
Receiving hostSupported cube dimensions and import requirements
Final checkKnown camera samples in the actual display path
  1. Check the host’s supported cube dimensions, file naming, and LUT import procedure.
  2. Place the LUT where it receives the selected camera log and gamut. Do not feed it a Rec.709 viewing transform when it expects camera log.
  3. Match the output target and full/legal handling. Avoid packing legal output twice.
  4. Avoid an extra creative look or display transform that changes the diagnostic colors.
  5. Test with known camera samples and a reference exposure. Confirm the result on the actual display before relying on the color labels.

A color-managed editor may automatically transform clips before or after a LUT node. Inspect that signal path rather than choosing a node location by habit. Device-specific menu names and calibration procedures belong to the device’s manual.

This LUT intentionally replaces image regions with diagnostic colors. Preserve an unaffected monitoring or review path when you need to judge the normal appearance of the image.
