Controls and colors

Finding your controls

Section titled “Finding your controls”

Use Presets, Edit, Preview, and Settings in the bottom navigation on a phone or side navigation on desktop. Edit contains Bands and Palette. Preview contains the photo illustration and camera verification. Settings contains camera, output, optional tools and saved setups; optional controls expand in place. Export LUT opens from the header and uses Close to return.

On mobile, Presets shows separate IRE, Fill, and Stops sections, with a colored exposure-strip preview for each choice. Stops use a −7 to +7 scale; IRE uses a 0–100 camera-log scale for your selected camera. The mode choices in Band setup & graph settings also show examples alongside their labels. Tap a preset’s Use button to apply it directly. Standard and Detailed options reuse the existing arrangements; Undo last band edit in Bands restores your previous bands and mode. Desktop keeps its preset picker.

The phone exposure graph scrolls with Bands. Palette has a compact preview; other tasks use the full screen without the exposure stage above their controls.

Imported IRE setups

Older setups can retain target-display IRE. Check the Legacy setup label before comparing their numbers with a new camera-log IRE setup.

Stops marks scene exposure relative to 18% gray. New IRE selections measure camera-log encoded RGB luma before the viewing conversion, on a full-code-range percentage scale. Older imported setups can retain target-display IRE; the editor labels them Legacy setup. Switch to camera-log IRE replaces their bands with fresh camera-centered presets and can be undone. Fill assigns a color to every exposure zone; the browser’s Fill mode uses stops.

Worked exposure examples

Section titled “Worked exposure examples”

For decoded source-gamut luminance Y, stops are log2(Y / 0.18). Thus Y = 0.09, 0.18, and 0.36 represent −1, 0, and +1 stop. The source gamut’s RGB-to-XYZ matrix supplies the luminance weights; this is not an average of the recorded RGB channels.

In a new camera-log IRE setup, a band at 50 with total width 10 covers encoded input luma from 45 to 55. Neutral 50 corresponds to code 511.5 on the full 10-bit-equivalent input scale. Changing output range does not change this measurement. The source gamut supplies the weights applied to encoded RGB; colored subjects need not rank the same way as scene-linear Stops. This scale does not promise an identical reading on every camera waveform or monitor.

The neutral 18% reference depends on the camera: approximately 41.1 for Sony, 42.3 for Panasonic, 34.3 for Canon, 39.1 for ARRI, 33.3 for RED, and 38.4 for Blackmagic. These use the existing profile curve defaults. Legacy target-display IRE instead uses target-encoded luma with a neutral reference around 40.9. JSON preserves the chosen interpretation. See the camera-log IRE reference. Neither interpretation supplies a universal skin-tone target.

Color picker

Section titled “Color picker”

Click a band or warning swatch. Use the saturation/value area and hue control, numeric color controls where shown, or enter a six-digit #RRGGBB value. The bundled named swatches provide another starting point. Invalid colors must be corrected before they can be applied. Escape closes the picker and returns focus. See keyboard controls for alternatives to pointing.

Palettes and gradients

Section titled “Palettes and gradients”

Recolor all bands changes colors without moving the bands. Editing a single swatch remains available if you want to keep the other colors.

Geometry and color are separate. A palette changes the labels on your existing bands. Applying an arrangement preset replaces positions and colors.

Starting exposure palettes anchor the reference at zero stops or the selected profile’s neutral camera-log IRE value. Legacy target-IRE setups retain the neutral target reference. Their end colors extend beyond the palette scale. Changing cameras updates the reference and palette scale; existing band numbers remain user edits until a preset is applied. Older saved custom gradients can instead span the current band range; their center is not necessarily the exposure reference. In Fill, colors cover whole zones.

Recorded-signal warnings

Section titled “Recorded-signal warnings”

Each checkbox enables one warning; its color picker changes only the indicator color. Neither control edits the numeric profile threshold. Read how the limits are calculated for purple/red interpretation, precedence, and cube-size tolerance.
